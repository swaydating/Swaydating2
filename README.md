# Sway Dating App

A modern dating app built with SwiftUI.

## Project Structure

- `Sway/` - Main application source code
  - `SwayApp.swift` - App entry point
  - `ContentView.swift` - Main authentication UI
  - `Assets.xcassets/` - App assets and icons
  - `Preview Content/` - Preview assets for Xcode

- `SwayTests/` - Unit tests
- `SwayUITests/` - UI tests

## Features

- User authentication with login and sign-up screens
- Dark mode UI
- Password strength indicator
- Form validation
- OAuth integration (Google & Apple - UI only)

## Requirements

- iOS 15.0+
- Xcode 14.0+
- Swift 5.5+

## Getting Started

1. Open `Sway.xcodeproj` in Xcode
2. Select a simulator or device
3. Build and run (⌘R)

## Development

The app uses SwiftUI for the UI and includes:

- Custom form components
- Password visibility toggle
- Email validation
- Password strength scoring
